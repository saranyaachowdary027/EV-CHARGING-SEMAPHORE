What is a counting semaphore?

threading.Semaphore(3)

A semaphore is a synchronization mechanism that controls how many threads may use a limited resource at the same time. A counting semaphore keeps a number of permits. A thread must obtain a permit before using a resource and return it when finished.

ACQUIRE — take a permit

If a permit is available, the request reserves one charging point. In the six-thread practical, acquire() waits when all permits are occupied.

WAIT — no permit available

Three EVs can charge at once. EV requests beyond that capacity must wait until a permit is returned.

RELEASE — return a permit

When charging completes, release() returns the permit. The next waiting EV can then use the free charger.

See the exact Python practical code
charging_sem = threading.Semaphore(3)

def charge_ev(ev):
    charging_sem.acquire()   # wait for a permit
    try:
        print(ev, "starts charging")
        time.sleep(1)        # simulate charging
    finally:
        charging_sem.release()  # return the permit

# create and start 6 EV threads; join them all

This is the blocking six-thread practical. The dashboard backend uses acquire(blocking=False) so it can save a visible FIFO waiting-queue record instead of blocking the web request. Both use the same three-permit capacity rule.
